# Muslim Wedding Invitation — Exact Reference Version

This website uses the two uploaded invitation artworks directly as the visual artwork.

- `assets/page-1.png` = the uploaded second image (cover / Page 1)
- `assets/page-2.png` = the uploaded first image (details / Page 2)
- The transparent OPEN hotspot is positioned over the OPEN button in Page 1.
- Clicking OPEN transitions to Page 2.
- A small back button appears on Page 2.
- No external libraries, fonts, CDNs, or internet connection are required.

## Run locally
Open `index.html` in a browser.
